### Highload Wallet V3 (High-Throughput)

| Operation             | Gas Used | Notes                           |
| --------------------- | -------- | ------------------------------- |
| Simple transfer       | 6,200    | +107% vs V3 (replay protection) |
| Transfer with comment | 6,200    | No additional overhead          |
| Batch 12 messages     | 7,956    | 663 gas per message             |
| Batch 50 messages     | 7,956    | 159 gas per message             |

**Best for**: Very large batches (50+ messages only)

**⚠️ Important Cost Consideration**: Highload uses a **2-transaction approach**<br/>
that significantly increases forward fees:

- **External message**: Triggers batch operation (6,200 gas compute)
- **Internal message**: Executes the actual batch (1,756 gas compute for 12 messages)
- **Total forward fees**: 0.00855 TON for 12 messages vs 0.00480 TON for V5 (1.8x higher)

**Key Insight**: Highload V3 achieves **46% gas savings** per message vs V3 baseline,<br/>
but the two-transaction approach creates ~1.8x higher forward fees, making it<br/>
cost-effective only for very large batches (50+ messages).

**Execution Model**:

- Single action → Direct execution from external message
- Multiple actions → Internal self-transfer for batch processing (adds transaction overhead)

For detailed analysis, see [Highload V3 Implementation Guide](docs/technical/highload-implementation.md).

## Implementation Details

### Enhanced Fee Tracking System

The gas-research project captures **all fee types**, not just gas:

```typescript
import { GasLogAndSave } from "./helpers/gas-logger";

const GAS_LOG = new GasLogAndSave("WalletV5");

// Record all fees from transaction(s)
GAS_LOG.rememberGas("batch_12_messages", transactions);

```

**Captured Metrics**:

- ✅ **Gas Used**: Raw TVM gas units
- ✅ **Compute Fee**: Gas cost in nanoTON
- ✅ **Storage Fee**: State storage cost
- ✅ **Forward Fee**: Message routing cost
- ✅ **Action Fee**: Output action cost
- ✅ **Total Fee**: Complete transaction cost
- ✅ **Transaction Count**: Number of transactions involved

### Compilation with TVM11

The harness uses a custom `myCompile()` function that:

1. Extracts compiler config from `.compile.ts` files in `wrappers/`
2. Compiles FunC contracts with optimization level 2
3. Saves fift output to `fift-output/` for debugging
4. Upgrades blockchain to TVM11 for production parity

**For Sandbox Tests:**

```typescript
import { myCompile, activateTVM11 } from "./helpers/my-compile";

// Compile contract
const code = await myCompile("HighloadWalletV3");

// Upgrade blockchain
blockchain = await Blockchain.create();
activateTVM11(blockchain);
```

**For Network Scripts:**

```typescript
import { compile } from "@ton/blueprint";

// Standard blueprint compilation (looks in wrappers/)
const code = await compile("HighloadWalletV3");
```

> **Note:** `.compile.ts` files must be in `wrappers/` for blueprint's `compile()` to work.

### Gas Logging

The `GasLogAndSave` class aggregates gas across transactions and persists metrics:

```typescript
import { GasLogAndSave } from "./helpers/gas-logger";

const GAS_LOG = new GasLogAndSave("HighloadWalletV3");
```

## Best Practices

### Writing Gas Tests

1. **Use myCompile()**: Ensures TVM11 and fift output
2. **Activate TVM11**: Call `activateTVM11(blockchain)` in `beforeEach`
3. **Use GasLogAndSave**: Aggregate gas properly across transactions
4. **Deterministic inputs**: Fixed timestamps, seeds, and addresses
5. **Mark as [bench]**: Prefix test names with `[bench]` for clarity

### Example Test Structure

```typescript
describe("Wallet Gas Measurement", () => {
  let GAS_LOG: GasLogAndSave;
  let blockchain: Blockchain;
  let code: Cell;

  beforeAll(async () => {
    code = await myCompile("WalletName");
    GAS_LOG = new GasLogAndSave("WalletName");
    GAS_LOG.rememberBocSize("WalletName", code);
  });

  afterAll(() => {
    GAS_LOG.saveCurrentRunAfterAll();
  });

  beforeEach(async () => {
    blockchain = await Blockchain.create();
    activateTVM11(blockchain);
    blockchain.now = CONTROLLED_TIMESTAMP;
  });

  it("[bench] simple transfer", async () => {
    // ... test implementation ...
    GAS_LOG.rememberGas("simple_transfer", result.transactions[0]);
  });
});
```
